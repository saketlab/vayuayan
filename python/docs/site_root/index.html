vayuayan

Air quality data for India: CPCB monitoring stations, OAQ low-cost sensors, and WUSTL ACAG satellite PM2.5, with the CPCB National AQI.

Python

pip install vayuayan

Python package and command-line tool.

R

install.packages("vayuayan", repos = "https://saketlab.r-universe.dev")

R package, with analysis articles for Delhi, Mumbai and other metros.

Air quality in your terminal

The Python package shows live and historical AQI on the command line, in the official category colours. With no place named, vayuayan live finds the station nearest to you.

$ pip install vayuayan
$ vayuayan live anand vihar
