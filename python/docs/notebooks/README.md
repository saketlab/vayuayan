# vayuayan notebooks

These Jupyter notebooks show how to use the vayuayan package.

## Notebooks

- `01_getting_started.ipynb`: basic use of the package
- `02_historical_data_analysis.ipynb`: historical AQI data analysis
- `03_live_monitoring.ipynb`: live AQI data
- `04_pm25_regional_analysis.ipynb`: PM2.5 regional analysis with GeoJSON
- `05_oaq_sensors_vs_cpcb.ipynb`: OAQ low-cost sensors, OAQ's daily records, and Airnet vs the nearest CPCB station (needs `OAQ_API_KEY`)
- `06_oaq_sensor_quality.ipynb`: quality assessment of Airnet sensors against the US EPA targets (needs `OAQ_API_KEY`)
- `07_oaq_daily_values.ipynb`: OAQ's daily value became the day's last 15-minute reading around 1 March 2026 (needs `OAQ_API_KEY`)

For an introduction, start with `01_getting_started.ipynb`.
